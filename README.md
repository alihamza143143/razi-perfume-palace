# Razi Perfume Palace

Single-page bilingual (EN+UR) luxury landing site for رضی پرفیوم پیلس — wholesale fragrance dealer in Kallar Syedan, Rawalpindi.

## Stack

Vite · Tailwind · GSAP · Lenis · Vanilla JS

## Local dev

```
npm install
npm run dev
```

## Build

```
npm run build
npm run preview
```

## Deploy

Auto-deployed to Vercel from `main`.
